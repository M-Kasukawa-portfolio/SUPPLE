# SUPPLE（架空・カフェサイト）

Hello Mentor 課題で制作した、架空カフェの店舗系サイトです。
Figmaのデザインカンプに基づきコーディングしました。

## Demo

https://mkdesignworks.net/portfolio/SUPPLE/

## 概要

- 内容: トップ／コンセプト／メニュー／店舗一覧／ブログなど複数ページの静的HTML
- 位置づけ: 学習課題（実務案件ではありません）
- 担当: コーディング（デザイン・レイアウト設計は含みません）
- 方針: カンプ準拠。レスポンシブはオーソドックスな実装

## 使用技術

HTML5 / Sass(SCSS) / JavaScript

## この課題で扱ったこと

複数ページ構成の静的サイトを、共通レイアウトとページ固有セクションに分けて実装しました。
PC／SPで画像やレイアウトが切り替わるオーソドックスなレスポンシブを通じて、
カンプ通りに再現するときのブレイクポイントや画像出し分けの考え方を学びました。
